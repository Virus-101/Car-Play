# Android Auto on an Android car head unit (no dongle)

Tested setup: Nissan Qashqai 2019, Magnav Android 7.1.1 head unit, Samsung S22, **wired USB**.

Uses [Headunit Revived](https://github.com/andreknieriem/headunit-revived) (v3.4.0), which makes the head unit act as an Android Auto screen for your Android phone. iPhone/CarPlay is not covered.

`C:\Users\..\Downloads\AutoKit_2025.03.19.1126.apk`

## 2. Install on the car screen (once)
1. Plug the stick into the car's USB port (the one that plays media).
2. Open the file manager, tap `HeadunitRevived.apk`, Install (allow unknown sources if asked).

## 3. Connect the phone
1. On the phone: update Android Auto; if needed tap its Version row ~10 times to enable developer mode.
2. Open Headunit Revived on the screen.
3. Plug the phone into the same USB port with a data cable and accept the prompts.

Notes: wireless mode needs Wi-Fi on the head unit plus a companion app and was not used. Not every unit's USB port supports phone connections.
